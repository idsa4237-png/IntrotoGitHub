IntrotoGitHub

A repository that's used to learn how to use Git like committing a file, using commands like "init", "config", etc. 

Installation Instructions:

1. Ensure you have Git installed on your system.
2. On the GitHub repository page, click the green Code button and copy the HTTPS URL.
3. Open your terminal (or Git Bash on Windows), navigate to the folder where you want the project, and run
git clone <repository-url>
